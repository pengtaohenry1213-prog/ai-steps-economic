## 二、立项背景与必要性

### （一）现有系统痛点

现有经济模型系统V1已实现基础测算功能，但存在**四大核心问题**：

1. **财务计算精度不足**：自研公式引擎维护成本高，专业财务函数计算易出现偏差；
2. **无协作能力**：仅支持单人编辑，多部门协同效率低下；
3. **无正式后端支撑**：仅Mock服务，无法满足数据持久化与业务扩展；
4. **安全合规缺失**：无完善权限、审计机制，不满足企业内控与等保要求。

### （二）立项必要性

1. **业务刚需**：满足多团队并行建模、财务数据精准测算、内网本地化部署的核心需求；
2. **技术升级**：替换高成本自研组件，采用成熟稳定的行业方案；
3. **合规落地**：实现权限管控、操作审计、数据脱敏，满足企业安全合规要求；
4. **效率提升**：简化操作流程，降低使用门槛，提升经济模型编制与管理效率。

## 三、项目建设目标

### （一）量化KPI（成功标准）

| 指标 | 目标值 | 衡量方式 |
|------|--------|----------|
| 计算精度 | XIRR/XNPV/NPV/IRR 与Excel偏差 = 0 | 对标Excel标准测试用例100%通过 |
| 协作效率 | 多部门建模效率提升 ≥50% | 对比V1单人与V2协作耗时 |
| 导入导出成功率 | Excel兼容率 ≥95% | 现有模板回归测试通过率 |
| 系统可用性 | ≥99.5% | 7×24监控 |
| 用户满意度 | NPS ≥ 40 | 上线后用户调研 |

### （二）核心目标

1. **计算精准**：财务函数（XIRR/XNPV/NPV/IRR）计算100%准确，对标Excel标准结果；
2. **协作高效**：支持多人实时在线编辑，无数据冲突，协同效率提升50%以上；
3. **数据安全**：敏感数据脱敏、全流程操作审计、精细化权限管控；
4. **兼容易用**：完全兼容现有Excel模板，支持一键导入导出，降低用户迁移成本；
5. **架构稳定**：技术架构模块化，支持后续AI辅助、功能扩展迭代。

## 四、核心建设内容

### （一）MoSCoW功能优先级

| 优先级 | 功能 | 说明 |
|--------|------|------|
| **Must have** | 模型与版本管理、表格编辑与计算、Excel导入导出、权限管控 | 上线前必须完成 |
| **Should have** | 多人实时协作、操作审计、数据备份 | 重要但有替代方案 |
| **Could have** | 智能辅助（AI提示、自然语言查询） | 锦上添花 |
| **Won't have** | 第三方支付集成、移动端App、公有云部署 | 本次不做 |

### （二）非功能需求

| 维度 | 要求 |
|------|------|
| **性能** | 表格渲染 ≤100ms（万行数据）、公式计算 ≤500ms、API响应 ≤200ms、并发用户 ≥50 |
| **安全** | 等保2级合规、操作审计日志、敏感数据脱敏、JWT鉴权 |
| **可用性** | 系统可用性 ≥99.5%、内网离线可用、数据自动备份 |
| **可维护性** | 模块化架构、自动化测试覆盖率 ≥70%、日志规范 |

### （三）技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                        前端（Vue3 + Vben Admin）             │
├─────────────────────────────────────────────────────────────┤
│  表格引擎（Luckysheet）  │  公式计算（ExcelJS/Formula）     │
└─────────────────────────┴───────────────────────────────────┘
                              │ HTTP/REST
┌─────────────────────────────────────────────────────────────┐
│                     后端（NestJS + TypeORM）                │
├──────────┬──────────┬──────────┬──────────┬────────────────┤
│ 用户模块  │ 模型模块  │ 权限模块  │ 审计模块  │  协作模块（v2） │
└──────────┴──────────┴──────────┴──────────┴────────────────┘
                              │
┌─────────────────────────────────────────────────────────────┐
│                     数据库（PostgreSQL）                     │
└─────────────────────────────────────────────────────────────┘
```

**技术选型**：Vue3 + NestJS + PostgreSQL + Luckysheet + Docker

### （四）外部依赖

1. **ExcelJS**：Excel文件解析与生成
2. **Luckysheet**：Web表格编辑引擎
3. **Supabase**：数据库与认证服务（可选自建）

### （五）核心必建功能（第一阶段）

1. **模型与版本管理**：支持模型创建、编辑、删除，版本状态管控（草稿/已提交/已锁定）；
2. **表格编辑与计算**：支持大数据量流畅展示、单元格编辑、财务公式自动计算；
3. **数据导入导出**：兼容现有模板，实现Excel批量导入、数据导出；
4. **权限与安全**：复用现有权限规则，实现数据隔离与操作权限管控。

### （六）扩展功能（第二阶段）

1. **多人实时协作**：多用户同步编辑、操作实时同步；
2. **系统保障**：错误定位、资源监控、数据自动备份与恢复；
3. **智能辅助**：公式智能提示、自然语言数据查询。
