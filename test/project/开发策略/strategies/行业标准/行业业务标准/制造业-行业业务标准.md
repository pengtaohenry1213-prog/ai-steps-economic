## 一、行业概述

### 1.1 行业背景

制造业是国民经济支柱产业，涵盖：

- 离散制造业（汽车、电子、设备）
- 流程制造业（化工、医药、食品）
- 智能制造（工业4.0、物联网）

### 1.2 核心业务特征

| 特征 | 说明 |
| --- | --- |
| **供应链驱动** | 物料采购、生产计划、交付履约是核心 |
| **质量为本** | 产品质量是生命线 |
| **批量生产** | 规模化降低成本 |
| **合规认证** | 安规、环保、行业标准认证 |

### 1.3 行业特有挑战

- 生产周期长，试错成本高
- 供应链复杂，供应商管理重要
- 工艺文件（SOP）是核心资产
- 设备联网（OT/IT融合）是趋势

---

## 二、行业特有流程

### 2.1 生产管理流程

```text
需求预测 → 物料采购 → 入库检验 → 生产排程 → 生产执行 → 质量检验 → 入库 → 发货
```

### 2.2 核心业务系统

| 系统 | 说明 |
| --- | --- |
| **MES** | 制造执行系统，管控生产过程 |
| **ERP** | 企业资源计划，财务+供应链 |
| **PLM** | 产品生命周期管理，BOM管理 |
| **QMS** | 质量管理系统，质检流程 |
| **WMS** | 仓库管理系统 |

### 2.3 物料清单（BOM）

| BOM类型 | 说明 |
| --- | --- |
| **设计BOM** | 工程设计阶段的物料清单 |
| **工艺BOM** | 制造工艺路线 |
| **生产BOM** | 用于生产排程的物料清单 |
| **成本BOM** | 用于成本核算的物料清单 |

### 2.4 生产工单

| 状态 | 说明 |
| --- | --- |
| **待生产** | 已下达，尚未开始 |
| **生产中** | 正在生产 |
| **暂停** | 因异常暂停 |
| **已完成** | 生产完成 |
| **已入库** | 物料/成品入库 |

## 三、行业规则与合规

### 3.1 生产许可

| 类型 | 说明 |
| --- | --- |
| **生产许可证** | 工业品生产需持证 |
| **安全认证** | 3C、CE、UL 等 |
| **环保认证** | ISO 14001、清洁生产 |
| **行业准入** | 特种设备、食品、药品等专项许可 |

### 3.2 质量标准

| 标准 | 说明 |
| --- | --- |
| **ISO 9001** | 质量管理体系 |
| **IATF 16949** | 汽车行业质量标准 |
| **GMP** | 药品生产质量管理规范 |
| **HACCP** | 食品安全控制体系 |

### 3.3 环保与安全

| 要求 | 说明 |
| --- | --- |
| **环评批复** | 建设项目环境影响评价 |
| **三同时** | 环保设施与主体工程同时设计/施工/投产 |
| **安全生产** | 职业健康安全管理体系（ISO 45001） |

## 四、行业数据模型

### 4.1 核心数据实体

| 实体 | 说明 | 关键属性 |
| --- | --- | --- |
| **物料（Material）** | 原材料、辅料、成品 | materialId、code、name、spec、unit、type |
| **BOM** | 物料清单 | bomId、productId、version、status |
| **BOM行（ BOMLine）** | BOM组成 | bomLineId、bomId、materialId、quantity、scrap |
| **工单（WorkOrder）** | 生产工单 | workOrderId、productId、quantity、status、startDate |
| **工艺路线（Routing）** | 制造工艺 | routingId、productId、version、status |
| **工序（Operation）** | 工艺工序 | operationId、routingId、sequence、workCenter、time |
| **质检单（QC）** | 质量检验 | qcId、workOrderId、sampleSize、result、inspector |

### 4.2 库存数据

| 类型 | 说明 |
| --- | --- |
| **原材料库存** | 采购物料库存 |
| **在制品（WIP）** | 工序间流转的半成品 |
| **成品库存** | 完工待发货产品 |
| **质检库存** | 待检或暂存区 |

### 4.3 批次追溯

| 追溯维度 | 内容 |
| --- | --- |
| **批次号** | 唯一标识 |
| **原料批次** | 使用的原料来源 |
| **生产批次** | 生产时间、设备、人员 |
| **质检记录** | 检验结果 |

## 五、开发注意事项

### 5.1 技术选型

| 建议 | 说明 |
| --- | --- |
| **工业协议** | OPC-UA、MQTT、Modbus 等 |
| **实时数据库** | TimescaleDB、InfluxDB |
| **消息队列** | Kafka（高吞吐） |
| **SCADA 接口** | 采集设备数据 |

### 5.2 性能要求

| 指标 | 要求 |
| --- | --- |
| **实时性** | OT 数据采集 < 100ms |
| **接口响应** | IT 系统 < 500ms |
| **可用性** | 生产线系统 ≥ 99.99% |
| **数据存储** | 历史数据保留 ≥ 3年 |

### 5.3 安全要求

| 类型 | 要求 |
| --- | --- |
| **网络隔离** | IT/OT 网络隔离 |
| **设备认证** | PLC、设备需认证接入 |
| **工控安全** | 工业防火墙 |
| **审计日志** | 操作记录可追溯 |

### 5.4 与MES系统集成

| 集成点 | 说明 |
| --- | --- |
| **工单下发** | ERP → MES |
| **报工回报** | MES → ERP |
| **物料消耗** | MES → ERP |
| **质检结果** | QMS → MES/ERP |
