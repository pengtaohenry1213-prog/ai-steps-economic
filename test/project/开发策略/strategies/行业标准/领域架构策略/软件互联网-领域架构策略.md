## 一、行业典型架构

### 1.1 互联网架构演进

| 阶段 | 架构模式 | 适用场景 |
|-----|---------|---------|
| **单体架构** | 所有模块在一个应用 | 初创期，小团队 |
| **垂直拆分** | 按业务线拆分 | 用户增长期 |
| **微服务架构** | 服务拆分，API通信 | 大型平台 |
| **云原生架构** | 容器化、弹性伸缩 | 需要快速弹性伸缩 |

## 二、技术选型要点

### 2.1 前端技术栈

| 层级 | 技术 | 说明 |
|-----|------|------|
| **框架** | Vue3 / React | 主流选择 |
| **状态管理** | Pinia / Redux Toolkit | 大型项目用 Redux |
| **构建工具** | Vite / Webpack | Vite 更快 |
| **CSS 方案** | TailwindCSS / UnoCSS | 原子化 CSS |
| **UI 组件** | Element Plus / Ant Design | 企业级组件 |

### 2.2 后端技术栈

| 层级 | 技术 | 说明 |
|-----|------|------|
| **语言** | Java (Spring Boot) / Go / Node.js | 按场景选择 |
| **框架** | Spring Cloud / Gin / Express | 微服务 / 轻量服务 |
| **网关** | Kong / APISIX / Spring Gateway | API 网关 |
| **注册中心** | Nacos / Consul / Eureka | 服务发现 |
| **配置中心** | Apollo / Nacos Config | 配置管理 |

### 2.3 数据技术栈

| 类型 | 技术 | 说明 |
|-----|------|------|
| **关系型数据库** | MySQL / PostgreSQL | OLTP |
| **缓存** | Redis Cluster | 热点数据 |
| **消息队列** | Kafka / RocketMQ | 高吞吐 |
| **搜索引擎** | Elasticsearch | 全文检索 |
| **对象存储** | OSS / S3 | 文件存储 |
| **时序数据库** | InfluxDB / TimescaleDB | 监控数据 |

## 三、集成模式

### 3.1 第三方登录集成

| 提供商 | 集成方式 | 注意事项 |
|-------|---------|---------|
| **微信** | OAuth2.0 + 微信登录SDK | 需要微信开放平台账号 |
| **Apple** | Sign in with Apple | iOS 必须支持 |
| **Google** | OAuth2.0 | 海外产品必备 |
| **GitHub** | OAuth2.0 | 开发者工具必备 |

└─────────────┘     └─────────────┘     └──────┬──────┘

## 五、高可用架构

### 5.1 多活架构

| 模式 | 说明 | 适用场景 |
|-----|------|---------|
| **同城双活** | 同城两机房 | 高可用 |
| **异地多活** | 多地域部署 | 灾难恢复 |
| **单元化** | 业务单元化 | 超大规模 |

### 5.2 降级熔断

```
                    ┌─────────────┐
                    │   请求      │
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │   熔断器    │
                    │  (Sentinel) │
                    └──┬───────┬──┘
                       │       │
              ┌────────▼┐    ┌▼────────┐
              │ 正常调用 │    │ 降级逻辑 │
              └─────────┘    └──────────┘
```

### 5.3 容灾备份

| 类型 | 策略 |
|-----|------|
| **数据备份** | 主从复制 + 跨机房备份 |
| **定时备份** | 每日全量 + 实时增量 |
| **演练** | 定期进行容灾切换演练 |

## 六、监控体系

### 6.1 监控层次

| 层次 | 工具 | 指标 |
|-----|------|------|
| **基础监控** | Prometheus + Grafana | CPU、内存、磁盘 |
| **应用监控** | SkyWalking / Jaeger | 调用链追踪 |
| **业务监控** | 自定义 Dashboard | DAU、转化率、订单量 |
| **日志监控** | ELK Stack | 日志聚合分析 |

### 6.2 告警策略

| 级别 | 说明 | 通知方式 |
|-----|------|---------|
| **P0** | 服务不可用 | 电话 + 短信 + 钉钉 |
| **P1** | 部分功能异常 | 短信 + 钉钉 |
| **P2** | 警告 | 钉钉 |
| **P3** | 提醒 | 邮件 |
