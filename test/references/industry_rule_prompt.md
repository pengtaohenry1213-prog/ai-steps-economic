在 AI 开发体系里，可以这样对应：

| 项目开发元素         | AI体系对应                    |
| -------------- | ------------------------- |
| 通用行业标准（工程标准）   | AI角色（Role/System Prompt）  |
| 垂直领域行业内容（业务规则） | Prompt（业务Prompt/任务Prompt） |

但这里要分层理解。

---

# 一、AI角色（Role）对应“通用开发策略”

AI角色本质：

```text id="2z4l3a"
定义 AI 是谁
具备什么能力
遵守什么规则
```

类似：

```text id="9xk2mp"
系统级开发规范
```

它更像：

* 软件架构规范
* 工程标准
* 技术中台规则

而不是具体业务。

---

# AI角色负责什么？

---

## 1. 行为规范

例如：

* 回复风格
* 输出格式
* 是否严谨
* 是否允许发散
* 是否必须结构化

类似：

```text id="7v5jq8"
代码规范
+
团队开发规范
```

---

## 2. 能力边界

例如：

* 你是SAP专家
* 你是Vue3专家
* 你是金融风控专家

类似：

```text id="f2nd7m"
技术架构定位
```

---

## 3. 全局规则

例如：

* 不允许编造
* 必须类型安全
* 必须考虑异常
* 必须考虑性能

类似：

```text id="4rj6up"
工程治理规范
```

---

# 所以：

AI Role 更像：

```text id="f2j9sw"
系统级工程标准
```

---

# 二、Prompt 对应“垂直行业内容”

Prompt 本质：

```text id="z8x7pr"
当前任务
+
当前行业规则
+
当前业务目标
```

它更像：

```text id="1p2v6y"
业务逻辑层
```

---

# Prompt 负责什么？

---

## 1. 行业规则

例如：

```text id="j9l3wp"
销售订单必须先审批
库存不足禁止出库
```

这是业务。

不是AI角色。

---

## 2. 当前任务

例如：

* 生成PPT
* 分析财务报表
* 编写Vue组件
* 输出SQL

这是任务层。

---

## 3. 上下文数据

例如：

* 当前用户信息
* 当前订单
* 当前表格数据
* 当前需求文档

这属于：

```text id="q5t1ka"
运行时上下文
```

---

# 三、最重要的一点

真正成熟的 AI 系统：

不是：

```text id="k4u8mm"
一个Prompt解决所有问题
```

而是：

```text id="p3m7an"
Role
+
Framework Prompt
+
Business Prompt
+
Runtime Context
```

---

# 四、对应到软件架构

可以这样理解：

| 软件系统 | AI系统             |
| ---- | ---------------- |
| 系统架构 | Role             |
| 行业规范 | Framework Prompt |
| 业务逻辑 | Business Prompt  |
| 请求参数 | Runtime Context  |

---

# 五、一个完整案例（ERP AI）

---

## AI Role（系统层）

```text id="31qv9j"
你是SAP SD/MM专家。
你必须：
- 遵守企业级架构规范
- 输出结构化JSON
- 必须考虑异常处理
- 必须保证字段完整
```

这是：

```text id="7v3s4r"
工程标准层
```

---

## Framework Prompt（行业层）

```text id="v5m8q2"
销售订单流程：
创建订单
→ 信用检查
→ 库存检查
→ 审批
→ 发货
→ 开票
```

这是：

```text id="c9n4tw"
行业流程层
```

---

## Business Prompt（任务层）

```text id="n2f8yu"
根据当前订单生成审批建议
```

这是：

```text id="w6r2mk"
业务任务层
```

---

## Runtime Context（运行数据）

```json
{
  "customer": "A公司",
  "amount": 200000,
  "stock": false
}
```

这是：

```text id="m4x8ps"
实时上下文
```

---

# 六、所以真正的 AI 开发策略

成熟体系一定是：

```text id="7h2v3m"
AI角色（工程标准）
+
行业Prompt（行业规则）
+
业务Prompt（业务任务）
+
上下文数据（运行态）
```

缺一个：

AI 都容易失控。
