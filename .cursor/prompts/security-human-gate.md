# Human Gate：Security 安全审查

## 触发时机（关键节点触发）

Security Human Gate 在以下关键节点触发，不频繁触发：

| 节点 | 触发条件 |
|------|----------|
| Gate 1 | Step 执行前（与 PMO 联合评审） |
| Gate 2 | Step 执行后（与 PMO 联合复审） |
| 敏感操作 | 涉及敏感数据处理时 |
| 危险命令 | 涉及系统命令执行时 |

## Gate 检查项

### 1. 文件操作安全

- [ ] **无路径穿越**：`..` 不出现在路径中
- [ ] **非系统目录**：不操作 `/etc/`, `/root/`, `/sys/`, `/proc/`
- [ ] **非敏感文件**：不覆盖 `.env`, `*.pem`, `credentials.json`, `*.key`
- [ ] **文件大小合理**：无超大文件（异常注入风险）

### 2. 命令执行安全

- [ ] **无危险命令**：
  - `rm -rf`（尤其带通配符）
  - `dd`（磁盘操作）
  - `mkfs`（文件系统创建）
  - `chmod 777`（权限过大）
  - `sudo` 无具体命令
  - 命令修改 `/etc/` 或系统文件
- [ ] **无命令注入**：使用参数数组，非字符串拼接
- [ ] **有超时机制**：防止无限进程

### 3. 密钥与凭证

- [ ] **无硬编码**：密钥/Token 不写在代码中
- [ ] **使用环境变量**：敏感信息从 `process.env` 读取
- [ ] **不输出明文**：日志中敏感字段已脱敏

### 4. 数据安全

- [ ] **敏感字段脱敏**：PII、财务、医疗等数据已掩码
- [ ] **无明文传输**：敏感接口使用 HTTPS
- [ ] **符合等保要求**：如涉及合规数据

## 统一决策格式

所有 Human Gate 必须使用以下统一决策格式：

| 决策 | 条件 |
|------|------|
| **PASS** | 所有安全检查项通过 |
| **CONDITIONAL** | 存在非致命风险，需额外注意，需记录处理建议 |
| **REJECT** | 存在高危风险，必须修复后才能继续 |

## 决策记录

```markdown
## Human Gate 决策

| 项目 | 内容 |
|------|------|
| Gate 类型 | Security |
| 触发节点 | Gate 1 / Gate 2 / 敏感操作 / 危险命令 |
| 操作类型 | 文件写入 / 命令执行 / API 调用 |
| 操作对象 | ... |
| 决策 | PASS / CONDITIONAL / REJECT |
| 风险描述（如有） | ... |
| 处理建议 | ... |
| 安全负责人 | ___ |
```

## 绝对禁止

```
- 路径穿越
- 系统文件操作
- 危险命令执行
- 硬编码密钥
- 明文敏感数据输出
```

## 闭环要求

- REJECT 操作必须终止，等待人工确认
- CONDITIONAL 操作需记录原因，操作后追加日志
- 所有安全事件需写入审计日志
