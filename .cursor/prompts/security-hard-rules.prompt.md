# 安全硬规则（来自 security-rules.md | 零妥协强制执行）

## 1. 文件操作禁令

- 禁止路径穿越（../）
- 禁止写入 /etc /root /sys /proc
- 禁止操作 .env *.pem credentials.json 等敏感文件
- 写文件前必须校验路径、类型、大小

## 2. 命令执行禁令

- 禁止 rm -rf / dd mkfs chmod 777 sudo
- 所有命令必须白名单校验
- 必须加超时、日志、参数化

## 3. 代码安全强制

- 无硬编码密钥、无明文密码
- 所有用户输入必须校验、转义
- SQL 使用参数化、防注入
- XSS/CSRF/IDOR/SSRF 基础防御

## 4. 数据安全强制

- 敏感数据（姓名/手机/税号/金额）必须脱敏
- 日志隐去密钥、密码、敏感信息
- 所有操作写入审计日志

## 5. 失败处理

- 失败必须安全返回，不泄露敏感信息
- 异常不暴露路径、代码、配置细节
