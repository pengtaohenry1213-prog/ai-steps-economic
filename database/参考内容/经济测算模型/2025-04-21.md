我来帮你分析一下 `addRelationData` 和 `getValue` 之间的使用逻辑和关系。

### 1. 整体关系

这两个函数是经济模型计算系统中的核心组件，它们共同工作来处理公式计算和指标关系：

- `addRelationData`: 负责构建指标之间的依赖关系图
- `getValue`: 负责根据指标代码获取实际的计算值

### 2. 具体分析

#### 2.1 addRelationData 的作用

`addRelationData` 主要处理以下几种特殊指标关系：

1. **全局变量 (global-)**:
```typescript
if (code.includes('global-')) {
  return;
}
```

2. **总计 (total-)**:
```typescript
if (code.includes('total-')) {
  realCode = code.split('-')[1];
  // 处理总计逻辑
}
```

3. **周期累计 (periodAdd-)**:
```typescript
if (code.includes('periodAdd-')) {
  realCode = code.split('-')[1];
  // 处理周期累计逻辑
}
```

4. **上期 (prev-)**:
```typescript
if (code.includes('prev-')) {
  const name = code.split('-')[1];
  // 处理上期逻辑
}
```

5. **所在期数 (var-everyPeriod)**:
```typescript
if (code.includes('var-')) {
  const name = code.split('-')[1];
  if (name === 'everyPeriod') {
    // 处理期数逻辑
  }
}
```

#### 2.2 getValue 的作用

`getValue` 函数根据不同的指标前缀来获取对应的值：

1. **全局变量**:
```typescript
if (mark.enCode.includes('global-')) {
  key = mark.enCode.replace('global-', '');
  data = globalConfig;
  value = data?.[key] || 0;
}
```

2. **总计**:
```typescript
if (mark.enCode.includes('total-')) {
  const code = mark.enCode.replace('total-', '');
  // 计算所有日期的总和
}
```

3. **上期**:
```typescript
if (mark.enCode.includes('prev-')) {
  const c = mark.enCode.split('-')[1];
  // 获取上期值
}
```

4. **周期累计**:
```typescript
if (mark.enCode.includes('periodAdd-')) {
  const c = mark.enCode.split('-')[1];
  // 计算从第一个周期到当前周期的累计值
}
```

### 3. 工作流程

1. **关系构建阶段**:
   - `addRelationData` 首先解析所有公式，构建指标之间的依赖关系
   - 它会识别特殊前缀（global-, total-, periodAdd-, prev-, var-）并建立相应的关系
   - 生成一个关系图，用于后续的计算顺序确定

2. **计算阶段**:
   - 当需要计算某个指标时，会调用 `getValue`
   - `getValue` 根据指标的前缀类型，采用不同的计算逻辑获取值
   - 计算过程中会考虑时间类型（年、季度、月）和周期数

### 4. 关键点

1. **时间处理**:
   - 系统支持年、季度、月三种时间类型
   - 不同时间类型会影响上期值的计算逻辑

2. **依赖关系**:
   - 通过 `addRelationData` 构建的依赖关系确保计算顺序的正确性
   - 避免循环依赖和计算顺序错误

3. **特殊指标处理**:
   - 每种特殊前缀都有其特定的计算逻辑
   - 这些逻辑在 `getValue` 中实现，确保计算结果的准确性

### 5. 示例说明

以公式 `${A0002}+${A0003}+${A0004}` 为例：

1. `addRelationData` 会识别这是一个普通公式，建立 A0002、A0003、A0004 与结果指标的关系
2. 当计算时，`getValue` 会分别获取这三个指标的值并相加

再以公式 `${prev-A0002}/${total-B0001}` 为例：

1. `addRelationData` 会识别 prev- 和 total- 前缀，建立相应的关系
2. 计算时，`getValue` 会：
   - 获取 A0002 的上期值
   - 获取 B0001 的所有期数总和
   - 进行除法运算

这种设计使得系统能够灵活处理各种复杂的计算场景，同时保持代码的可维护性和可扩展性。
