### 🧮 算法核心：Kahn 算法 + BFS

#### `kahnTopologicalSort` 函数核心流程
这是一个完整的 **Kahn 算法 + BFS** 实现，用于拓扑排序。以下是核心流程：

##### 📌 输入输出
```typescript
// 输入: graph - 节点依赖关系图
// node -> [依赖的节点数组]，表示 node 依赖 deps 中的所有节点
graph = {
  "C10001A0319-2025": ["C10001A0322-2025", "C10001A0045-2025"],
  ...
}
// 输出: 包含排序结果、环检测信息等
```

##### 🔄 核心流程（5步）
- **第1步：初始化入度表 & 反向邻接表**
- **第2步：构建反向邻接表: dep -> [依赖 dep 的所有节点] & 计算初始入度**
	**图示说明：**
		```
		原始图 (graph):                    反向邻接表 (adj):
		  A → [B, C]        =>              B → [A]
		  B → [D]           =>              C → [A]
		  C → [D]           =>              D → [B, C]
		```
- BFS 主循环（Kahn 算法核心）**
	- 1. 入度为0的节点作为起点（无任何依赖，可以最先计算）
	- 2. 找到所有依赖当前节点的"邻居"
	- 3. 遍历邻居，入度-1，如果变为0则加入队列
	
	**执行过程图解：**
	```
	初始状态: inDegree = { A:0, B:1, C:1, D:2 }, queue = [A]
	
	第1轮: 取 A，neighbors = [B, C]
	      inDegree[B] = 1-1 = 0 → 加入 queue
	      inDegree[C] = 1-1 = 0 → 加入 queue
	      queue = [B, C], order = [A]
	
	第2轮: 取 B，neighbors = [D]
	      inDegree[D] = 2-1 = 1
	      queue = [C], order = [A, B]
	
	第3轮: 取 C，neighbors = [D]
	      inDegree[D] = 1-1 = 0 → 加入 queue
	      queue = [D], order = [A, B, C]
	
	第4轮: 取 D，neighbors = []
	      order = [A, B, C, D] ✅ 排序完成
	```

- DFS 环路径检测（如有环）**
	使用 DFS 检测环的详细路径: **找到环，提取路径 -> 递归检查依赖...**

### ✅ 核心要点总结

| 步骤 | 关键点 |
|------|--------|
| **入度计算** | 统计每个节点有多少条边指向它 |
| **BFS 队列** | 入度为0的节点可先计算 |
| **更新邻居** | 处理完一个节点后，更新其邻居的入度 |
| **环检测** | `order.length < totalNodes` 说明有环 |
| **性能优化** | 使用索引指针 `queueIndex++` 代替 `shift()` |

### ⚠️ 难点与挑战

根据代码分析，系统面临的挑战包括：

1. **大规模数据计算**
   - 节点数量可能达到数千甚至更多
   - 使用 **Web Worker** 避免阻塞主线程

2. **循环依赖检测**
   - 代码中实现了完整的 **DFS 环检测算法**
   - 能够识别并报告循环依赖的具体路径

3. **复杂的时间维度计算**
   - 支持年度/季度/月度混合计算
   - 需要处理 `SUMIF`、`NPV`、`IRR` 等复杂财务函数

4. **性能优化**
   - 使用 **索引指针代替 shift()** (O(1) vs O(n))
   - 支持预计算的拓扑排序数据缓存
   - 分年份/季度预生成排序结果
