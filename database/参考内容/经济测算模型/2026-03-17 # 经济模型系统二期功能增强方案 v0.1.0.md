# 经济模型系统二期功能增强方案

## 项目背景

- **目标用户**: 大型企业（财务部门）

- **部署方式**: 私有化部署

- **核心目标**: 将经济模型系统打造为可市场推广的企业级产品

---

## 1. 用户体验与界面优化

### 智能公式编辑器增强

**目标**: 降低用户学习成本，提升公式编写效率
**功能点**:
- [ ] **公式智能提示**: 输入 `${` 时自动弹出指标选择下拉框，支持搜索和模糊匹配
- [ ] **公式语法高亮**: 对公式中的指标、常量、函数进行不同颜色高亮显示
- [ ] **公式版本管理**: 保存公式历史版本，支持回滚和对比


**参考实现文件**:
- [apps/web-ele/src/views/table/model_formula/edit.vue](../../apps/web-ele/src/views/table/model_formula/edit.vue) - 公式编辑页面
- [apps/web-ele/src/views/instance/edit/utils/calculate.ts](../../apps/web-ele/src/views/instance/edit/utils/calculate.ts) - 计算引擎

## 2. 协作与工作流

### 多用户协作编辑

**目标**: 支持团队多人同时编辑同一模型
**功能点**:
- [ ] **实时协作**: 基于 WebSocket 实现多人同时编辑，实时同步变更
- [ ] **锁机制**: 单元格/区域锁定，防止编辑冲突
- [ ] **操作日志**: 记录所有操作，支持审计和回溯
- [ ] **评论与标注**: 单元格可添加评论和标注，@相关人员
- [ ] **任务分配**: 将模型不同部分分配给不同人员

**参考实现文件**:
- [apps/web-ele/src/api/core/locker.ts](../../apps/web-ele/src/api/core/locker.ts) - 编辑锁机制 API
- [packages/stores/src/modules/lock.ts](../../packages/stores/src/modules/lock.ts) - 锁状态管理
- [apps/web-ele/src/store/model.ts](../../apps/web-ele/src/store/model.ts) - 模型状态管理（包含版本历史）
- [apps/web-ele/src/views/instance/edit/index.vue](../../apps/web-ele/src/views/instance/edit/index.vue) - 表格编辑页面（协作编辑入口）

## 3. 计算引擎优化
### 错误处理增强

**目标**: 在每个单元格中，附加"计算过程"功能，提供更好的错误诊断能力
**功能点**:
- [ ] **错误定位**: 快速定位计算错误的具体单元格
- [ ] **错误传播**: 显示错误如何传播到其他单元格
- [ ] **建议修复**: 根据错误类型提供修复建议（比如：排除循环引用相关单元格、排除依赖缺失相关单元格、排除计算结果异常相关单元格等）
- [ ] **调试模式**: 逐步执行公式，显示每一步的计算结果和中间变量

**参考实现文件**:
- [apps/web-ele/src/views/instance/edit/utils/cycle.ts](../../apps/web-ele/src/views/instance/edit/utils/cycle.ts) - 循环依赖检测
- [apps/web-ele/src/views/instance/edit/utils/dependencies.ts](../../apps/web-ele/src/views/instance/edit/utils/dependencies.ts) - 依赖关系分析
- [apps/web-ele/src/views/instance/edit/utils/calculate.ts](../../apps/web-ele/src/views/instance/edit/utils/calculate.ts) - 计算引擎（错误处理核心）
- [apps/web-ele/src/views/instance/edit/utils/topological.ts](../../apps/web-ele/src/views/instance/edit/utils/topological.ts) - 拓扑排序（依赖链分析）
- [apps/web-ele/src/views/instance/edit/workers/sort/index.ts](../../apps/web-ele/src/views/instance/edit/workers/sort/index.ts) - Web Worker 计算（计算稳定性）

## 4. 运维与监控

### 系统监控

**目标**: 保障系统稳定运行
**功能点**:
- [ ] **资源监控**: 监控 公式、表格、计算引擎、数据库等资源使用情况
- [ ] **健康检查**: 提供系统健康检查（围绕数据完整性、公式正确性及依赖关系，对表格计算逻辑进行全面校验与异常检测。）

**参考实现文件**:
- [apps/web-ele/src/views/instance/edit/utils/calculate.ts](../../apps/web-ele/src/views/instance/edit/utils/calculate.ts) - 计算引擎（可扩展计算稳定性检测）
- [apps/web-ele/src/views/instance/edit/utils/dependencies.ts](../../apps/web-ele/src/views/instance/edit/utils/dependencies.ts) - 依赖关系检查（循环依赖、依赖缺失检测）
- [apps/web-ele/src/views/instance/edit/components/BaseInfo.vue](../../apps/web-ele/src/views/instance/edit/components/BaseInfo.vue) - 表格基本信息（完整性检查入口）

| 模块            | 作用         | 其他                                                                                             |
| ------------- | ---------- | ---------------------------------------------------------------------------------------------- |
| 完整性检查         | 有没有缺数据     | - 必填单元格为空、必填公式缺失、关键字段未填写                                                                       |
| 数据正确性检查（数据质量） | 数据/公式填得对不对 | 检测内容：数据类型错误（数字/日期）、数据范围错误（>0、<=100）、格式错误（日期/手机号）                                               |
| 公式正确性检查       | 公式本身有没有问题  | 检测内容：语法错误 =A1+B?、引用不存在单元格、除0错误、函数使用错误                                                          |
| 依赖关系检查        | 引用是否正确     | 检测内容：✔ 循环依赖（重点）: A1 = B1, B1 = A1【x】✔ 依赖缺失: A1 = B1 + C1, C1 不存在 【x】✔ 依赖链分析: A1 → B1 → C1 → D1 |
| 计算稳定性(计算结果校验) | 是否能正常计算    | 检测内容：NaN / Infinity、超出合理范围、与历史数据差异过大                                                           |

### 5. 备份与恢复

**目标**: 数据安全保障
**功能点**:
- [ ] **自动备份**: 定时自动备份数据
- [ ] **手动备份**: 支持手动触发备份
- [ ] **增量备份**: 只备份变更数据
- [ ] **一键恢复**: 快速恢复到指定备份点
- [ ] **跨环境迁移**: 支持数据在不同环境间迁移
