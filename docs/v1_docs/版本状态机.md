## 12. 版本状态机

```
                    ┌─────────────┐
                    │   DRAFT     │  (status: 0)
                    │   草稿       │
                    └──────┬──────┘
                           │
                           │ 用户点击「提交」
                           ▼
                    ┌─────────────┐
                    │ SUBMITTED   │  (status: 1)
                    │   已提交     │ ←── 锁定编辑
                    └──────┬──────┘
                           │
                           │ 管理员可「退回」
                           ▼
                    ┌─────────────┐
                    │   DRAFT     │  (status: 0)
                    │   草稿       │
                    └─────────────┘
```
