## 5. 单元格组件模块

### 5.1 `Input.vue` - 输入组件

**文件位置**: `views/instance/edit/components/Input.vue`

**职责**: 处理单元格输入，支持刻度转换

**核心逻辑**:

```vue
<script setup>
const onChange = (val) => {
  if (val === '') {
    emit('update:modelValue', '');
    emit('change', '');
  } else if (scale > 0) {
    // 用户输入值 × 刻度 = 基础单位值
    const res = new Decimal(val).mul(scale).toNumber();
    emit('update:modelValue', res);  // 回写刻度转换后的值
    emit('change', res);               // 触发变更
  }
};
</script>
```

**刻度转换示例**:

| 显示值 | scale | 存储值 |
|--------|-------|--------|
| 100 | 1000 | 100000 |
| 1.5 | 10000 | 15000 |
