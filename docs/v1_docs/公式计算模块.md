### 2.1 `topological.ts` - Kahn 拓扑排序

**文件位置**: `views/instance/edit/utils/topological.ts`

**职责**: 对指标依赖关系图进行拓扑排序，确定计算顺序

**算法核心**:

```typescript
function topologicalSort(dag: DAG): string[] {
  // 1. 构建邻接表 inDegree
  const inDegree = new Map<string, number>();
  const graph = new Map<string, string[]>();
  
  // 2. 入度为0的节点入队
  const queue = [...allNodes].filter(node => inDegree.get(node) === 0);
  queue.sort((a, b) => a.localeCompare(b));  // 稳定排序
  
  // 3. Kahn 算法主循环
  while (queue.length > 0) {
    const current = queue.shift();
    topoOrder.push(current);
    
    for (const neighbor of graph.get(current)) {
      inDegree.set(neighbor, inDegree.get(neighbor) - 1);
      if (inDegree.get(neighbor) === 0) {
        insertSorted(queue, neighbor);  // 二分查找插入
      }
    }
  }
  
  // 4. 环检测
  if (topoOrder.length !== allNodes.size) {
    throw new Error(`图中存在环，涉及节点: ${[...remaining].join(',')}`);
  }
  
  return topoOrder;
}
```

**稳定性保证**: 使用 `localeCompare` 和二分查找插入，保证排序结果一致性

### 2.2 `dependencies.ts` - 依赖图生成

**文件位置**: `views/instance/edit/utils/dependencies.ts`

**职责**: 解析公式表达式，生成指标依赖关系图

**特殊表达式处理器**:

| 表达式 | 说明 | 示例 |
|--------|------|------|
| `lastPeriod-{code}` | 年末值 | `lastPeriod-C10001` → 取当前年度最后一个值 |
| `arrayAllValue-{code}` | 所有周期值数组 | → `[val1, val2, ...]` |
| `total-{code}` | 所有日期值数组 | 同上 |
| `prevPeriodAdd-{code}` | 往期累计（不含当前） | → sum of val[0..n-1] |
| `periodAdd-{code}` | 周期累计（含当前） | → sum of val[0..n] |
| `futurePeriodAdd-{code}` | 后期累计（不含当前） | → sum of val[n+1..end] |
| `prev-{code}` | 上期值 | → val[n-1] |
| `totalYear-{code}` | 年合计 | → 同年所有季度求和 |

### 2.3 `cycle.ts` - 环检测

**文件位置**: `views/instance/edit/utils/cycle.ts`

**职责**: 检测 DAG 中的环形依赖

**算法**: DFS + 递归栈

```typescript
function detectCycles(dag: DAG): string[][] {
  const visited = new Set<string>();
  const recursionStack = new Set<string>();
  const cycles: string[][] = [];
  
  function checkCycle(node, currentPath) {
    if (recursionStack.has(node)) {
      // 发现环，记录路径
      const cyclePath = currentPath.slice(currentPath.indexOf(node));
      cyclePath.push(node);
      cycles.push(cyclePath);
      return;
    }
    
    if (visited.has(node)) return;
    
    visited.add(node);
    recursionStack.add(node);
    currentPath.push(node);
    
    for (const neighbor of dag[node] || []) {
      checkCycle(neighbor, currentPath);
    }
    
    recursionStack.delete(node);
    currentPath.pop();
  }
}
```

### 2.4 `calculate.ts` - 公式计算引擎

**文件位置**: `views/instance/edit/utils/calculate.ts`

**职责**: 根据拓扑排序结果执行公式计算

**执行流程**:

```plain
1. 预计算常量
   ├── periodMonths: 时间段月数
   ├── periodNumber: 周期数量
   ├── arrayAllPeriod: 所有周期数组
   ├── targetIndustry: 目标行业
   └── investmentType: 投资类型

2. 全局变量处理器
   └── global-*: 不产生依赖的全局变量

3. 特殊表达式处理器
   └── prefix-{code}: 时间相关聚合计算

4. 解析公式
   ├── 提取变量 ${...}
   ├── 替换为实际值
   └── 处理连续负号

5. 执行计算
   └── FunctionCore.executeFunction(newExpr)
```

**计算结果处理**:

| 结果类型 | 处理方式 |
| --- | --- |
| `boolean` | 转换为 `'TRUE'` / `'FALSE'` |
| `number` | 有限值保留，否则 `'NaN'` |
| `string` | `#ERROR` 时记录到日志 |
| 其他 | 记录到非法数据日志 |
