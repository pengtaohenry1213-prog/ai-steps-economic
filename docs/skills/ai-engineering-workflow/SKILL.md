# AI 工程化工作流

## 任务目标

本 Skill 用于指导 AI 工程化开发的全生命周期管理，包括：
- 12 阶段开发流程规范（立项→需求→架构→初始化→开发→测试→验收→打包→部署→运维→迭代）
- v1 到 v2 系统升级规划与执行
- 技术栈选型与架构设计
- 代码规范与质量管控

**触发场景**：
- 用户需要制定项目开发计划
- 用户询问 v1 升级 v2 的技术方案
- 用户需要 AI 工程化规范指导
- 用户需要技术架构设计建议

## 前置准备

### 依赖说明
- `semver`: 版本号解析与比较

### 非标准文件准备
无需额外系统命令

## 操作步骤

### 步骤 1: 需求分析
1. 识别用户当前所处开发阶段（1-12 阶段）
2. 判断是否为 v1→v2 升级场景
3. 确定目标技术栈（Vue3/NestJS/PostgreSQL 等）

### 步骤 2: 规范匹配
1. 根据当前阶段匹配对应规范文档
2. 调用 `scripts/phase-matcher.js` 获取阶段详细规范
3. 输出阶段检查清单

### 步骤 3: 升级规划（v1→v2 场景）
1. 分析 v1 资产复用清单
2. 评估技术改造点
3. 生成分阶段迁移计划

### 步骤 4: 输出交付物
1. 阶段规范检查清单
2. 技术架构建议
3. 风险与应对措施

## v1→v2 升级核心差异

| 维度 | v1 (现有) | v2 (目标) |
|------|-----------|-----------|
| 公式引擎 | 自研 FunctionCore | HyperFormula |
| 协作机制 | 单人编辑 | Yjs CRDT 多人实时协作 |
| 智能助手 | 无 | RAG + LLM |
| 后端 | Nitro Mock | Supabase 本地化 |
| 状态管理 | Pinia | Zustand + Yjs Y.Map |
| 安全 | 前端权限控制 | RBAC + RLS + 审计日志 |

- 充分利用智能体能力，避免为简单任务编写脚本
