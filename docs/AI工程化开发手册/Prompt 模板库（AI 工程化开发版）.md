# Prompt 模板库（AI 工程化开发版）

---

# 一、Prompt 的真正作用

很多人以为 Prompt 是：

> “问 AI 的一句话”

实际上：

# Prompt 是 AI 的任务说明书

Prompt 写得越清楚：

- AI 越稳定
    
- 输出越可控
    
- Bug 越少
    
- 重构风险越低
    

---

# 二、AI 工程化 Prompt 核心原则

---

# 核心公式

```txt
背景
+ 目标
+ 限制
+ 禁止事项
+ 输出要求
```

---

# 三、万能工程 Prompt（最重要）

```txt
这是一个 [技术栈] 项目。

目标：
[明确功能目标]

限制：
- 保持现有技术栈
- 不新增依赖
- 保持现有代码风格
- 保持移动端兼容

禁止：
- 不要重构无关模块
- 不要修改UI风格
- 不要修改接口结构

输出：
1. 修改方案
2. 涉及文件
3. 风险点
4. 修改原因

先分析，不要直接写代码。
```

# 九、代码 Review Prompt（强烈推荐）

AI 写完代码后：

必须 Review。

---

## Code Review 模板

```txt
请Review以下修改。

重点检查：
1. 是否误改无关代码
2. 是否有重复逻辑
3. 是否有性能问题
4. 是否有安全风险
5. 是否存在空值风险
6. 是否存在类型问题
7. 是否存在副作用

输出：
- 风险列表
- 建议修改
- 严重等级
```
