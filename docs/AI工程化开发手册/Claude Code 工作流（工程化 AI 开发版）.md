# Claude Code 工作流（工程化 AI 开发版）

---

# 一、Claude Code 的定位

Claude Code 的真正定位不是：

> “AI 帮你生成代码”

而是：

# AI 工程协作系统

Claude Code 更强的地方：

- 长上下文理解
    
- 多文件联动
    
- 架构分析
    
- 重构能力
    
- 工程规划
    
- 文档生成
    
- Debug 推理
    

所以：

> Claude Code 更适合“中大型项目协作”。

而不是：

> 只生成几个按钮页面。

---

# 二、Claude Code 最适合做什么

---

# 最强场景

✅ 老项目维护  
✅ 中大型前端项目  
✅ 全栈项目  
✅ 重构项目  
✅ 架构优化  
✅ Bug排查  
✅ 文档工程化  
✅ 多模块联动开发

---

# 一般场景

✅ Vue3  
✅ React  
✅ Next.js  
✅ Node.js  
✅ Electron  
✅ 管理后台  
✅ AI应用

---

# 不适合

❌ 超高实时系统  
❌ 强安全金融核心  
❌ 完全无人监管开发

---

# 三、Claude Code 核心思想

Claude Code 的核心不是：

> “让 AI 自己发挥”

而是：

# 人类控制上下文

# AI 负责工程执行

# 四、Claude Code 标准工作流（核心）

---

# Stage1：项目初始化（最关键）

---

## 第一步：让 Claude 理解项目

不要直接：

❌ “帮我写功能”

正确做法：

```txt
请先阅读整个项目。

分析：
1. 技术栈
2. 目录结构
3. 状态管理
4. API结构
5. UI体系
6. 构建方式
7. 核心业务模块

不要修改代码，
只输出分析结果。
```

---

## 第二步：让 Claude 输出项目地图

要求输出：

- 模块关系
    
- 数据流
    
- 页面流
    
- 风险模块
    
- 历史遗留问题
    

目的：

> 建立 AI 的全局上下文。

---

## 第三步：建立工程文档

建议项目根目录：

```txt
PRD.md
ARCH.md
PROJECT_STATE.md
TODO.md
CHANGELOG.md
```

---

## PROJECT_STATE.md 推荐结构

```txt
当前阶段：
当前功能：
已完成：
当前问题：
禁止修改：
下一步：
```

每次开始开发：

> 先让 Claude 阅读 PROJECT_STATE.md

✅ “先完成登录页面静态UI”

# 五、Claude Code 最推荐开发模式

---

# 模式1：方案模式（强烈推荐）

不要直接让 AI 写代码。

先：

```txt
先不要写代码。

请输出：
1. 实现方案
2. 文件修改清单
3. 数据流变化
4. 风险点
5. 是否影响旧功能
```

确认后：

再开始生成代码。

---

# 模式2：最小修改模式

永远强调：

```txt
只做最小必要修改，
不要重构无关模块。
```

因为：

> Claude 很喜欢“顺手优化”。

这是最大风险之一。

---

# 模式3：模块隔离模式

例如：

```txt
只允许修改：

src/views/user
src/api/user

禁止修改：

- router
- layout
- global style
- store
```

---

```txt
输出：
1. 修改文件列表
2. 修改原因
3. 风险说明
```

# 七、Claude Code 工程纪律

---

# 1. 禁止 AI 自由重构

Claude 最大问题：

> 太喜欢“帮你优化”。

结果：

- 改一处
    
- 崩十处
    

所以必须明确：

```txt
不要顺手优化。
不要主动重构。
不要修改无关逻辑。
```

---

# 2. 一个功能一个会话

不要：

- 一个会话开发整个项目
    

因为：

- 上下文漂移
    
- AI开始遗忘规则
    
- 风险越来越高
    

建议：

✅ 一个功能一个会话  
✅ 一个Bug一个会话

---

# 3. 文件不要太大

Claude 对超大文件：

- 理解容易偏
    
- 修改容易误伤
    

建议：

- 单文件控制在 300~500 行
    
- 超过就拆模块

# 八、Claude Code Debug 工作流（重点）

---

# 错误示范

```txt
报错了，帮我修。
```

---

# 正确方式

```txt
问题：
点击保存按钮后页面白屏。

现象：
控制台报错：
xxx

复现步骤：
1.
2.
3.

最近修改：
修改了用户权限模块。

怀疑：
可能是权限数据为空导致。
```

---

# 九、两次无新增证据原则（极重要）

如果：

- 连续两次没修好
    
- 没新增信息
    
- AI开始乱改
    

必须停止。

---

# 正确处理方式

---

## 1. 最小复现

缩小问题范围。

---

## 2. 打日志

打印：

- 参数
    
- 请求
    
- 返回值
    
- 状态变化
    

---

## 3. 写测试

锁定当前行为。

---

## 4. Git回滚

回到稳定版本。

# 十一、Claude Code 安全规范

---

# 1. 密钥禁止进前端

禁止：

```txt
const API_KEY = "xxx"
```

必须：

```txt
.env
```

---

# 2. 服务端必须鉴权

不要信任前端。

必须：

- 权限校验
    
- 参数校验
    
- Token校验
    

---

# 3. AI 生成代码必须人工审核

重点审核：

- SQL
    
- 登录
    
- 上传
    
- 权限
    
- 支付
