# 结合 **Claude Code**（擅长复杂逻辑、长上下文、架构/全文件生成）与 **Cursor**（AI 原生 IDE，实时补全、对话、Agent 操作），可以形成一套高效、标准化的 **AI 驱动开发全流程**。

下面按 **立项→需求→开发→测试→验收→部署→迭代** 完整拆解，并明确每一步 **Claude/Cursor 怎么用、谁来用、注意事项**。

---

## 一、环境准备（前置）

### 1. 工具安装与配置

**参与角色**：开发、架构师、AI 应用工程师
**Claude Code 配置**

- 网页版：<https://claude.ai> → 选择 **Claude Code**（或 Claude 3/4 Sonnet）
- CLI 版：`npm install -g @anthropics/claude-code` → 登录、配置 API Key

**Cursor 配置（核心）**

- 下载安装：<https://cursor.com> → 用 GitHub 登录
- 模型设置（Ctrl+,）：
  - Provider: `anthropic` / `cursor`
  - Default Model: `claude-4-sonnet` / `claude-4.6`（长上下文、强代码）
  - Temperature: `0.1–0.3`（编程更稳定）
  - Context Window: 最大（200k+ tokens）
- 项目规则（必做）：
  - 新建 `.cursor/rules`（项目级）
  - 定义：技术栈、目录结构、命名规范、注释要求、错误处理、权限规范

  ```
  # 示例 .cursor/rules
  技术栈：Vue3 + TypeScript + Pinia + Express
  目录：src/components, src/views, src/utils, src/server
  注释：必写 JSDoc，函数/接口/类都要有说明
  风格：ESLint 标准，变量小驼峰，常量全大写
  安全：敏感数据加密，接口必鉴权
  ```

**协同模式（最佳实践）**

- **Claude Code**：做架构、全文件生成、复杂逻辑、跨模块分析、Prompt 优化
- **Cursor**：实时补全、内联修改、单文件调试、测试用例、本地运行、Agent 重构

## 二、项目立项 & 可行性评估

**参与角色**：产品负责人、技术负责人、业务方、管理层
**步骤与工具用法**

1. **业务目标与场景梳理**
   - 产品/业务：口述/文档写清：解决什么问题、用户、核心场景、KPI
   - **Claude**：
     - Prompt：`分析以下AI项目需求，做可行性评估、竞品分析、风险点、收益估算`
     - 输出：可行性报告、技术路线对比、成本预估
2. **AI能力边界确认**
   - **Claude**：`这个AI功能（如RAG问答/Agent自动执行）在Claude/Cursor上实现的可行性、准确率上限、延迟、幻觉风险、降级方案`
   - 输出：能力清单、不可行点、替代方案
3. **立项审批**
   - 输出：立项书、范围、里程碑、预算
**注意事项**

- 不夸大AI效果：明确 hallucination、冷启动、数据依赖
- 提前定：私有化/云端、数据不出网、脱敏要求

## 三、需求分析 & PRD（AI 辅助）

**参与角色**：产品经理、业务方、研发负责人、AI 应用工程师
**步骤与工具用法**

1. **需求收集与整理**
   - 产品：访谈、问卷、用户故事
   - **Claude**：粘贴访谈记录 → `提炼核心需求、痛点、用户故事、验收标准`
2. **PRD 自动生成**
   - **Claude**：

     ```
     基于以下需求，输出完整PRD：
     1. 项目背景
     2. 核心功能清单（用户/管理员/AI接口）
     3. 业务流程图
     4. 页面/接口清单
     5. 非功能：性能、并发、安全、兼容
     6. 验收标准
     ```

   - 输出：结构化 PRD、流程图文本、原型说明
3. **需求评审**
   - 产品+业务+技术：评审PRD，**AI只辅助，人终审**
4. **拆解为开发任务**
   - **Claude**：`把PRD拆成开发任务，按模块、优先级、依赖、预估工时`
   - 输出：任务清单（可导入看板）
**注意事项**

- 需求必须**可量化、可测试**，避免模糊描述
- AI模块单独列：模型选型、Prompt、知识库、RAG/Agent 逻辑

## 四、架构设计 & 技术方案（Claude 强项）

**参与角色**：架构师、后端/前端负责人、AI 算法/应用工程师、运维
**步骤与工具用法**

1. **整体架构设计**
   - **Claude**（长上下文最强）：

     ```
     设计一套AI驱动系统架构：
     前端：Vue3
     后端：Express
     AI层：Claude API + RAG + 向量库（Weaviate）
     要求：
     - 分层清晰（接入/业务/AI/数据）
     - 可扩展：模型替换、向量库迁移
     - 安全：鉴权、限流、数据脱敏
     - 部署：Docker + CI/CD
     输出架构图文字描述、组件关系、技术栈选型、关键接口
     ```

   - 输出：架构文档、技术栈清单、接口规范、错误码、权限设计
2. **AI 模块专项设计**
   - **Claude**：

     ```
     设计RAG系统：
     - 文档解析/分块/清洗
     - 向量库选型与 schema
     - Prompt 模板（系统+用户+历史+知识库）
     - 检索重排、答案校验、幻觉过滤
     - 日志与监控
     ```

3. **数据库 & 表结构**
   - **Claude**：生成 SQL / Prisma / Mongoose  schema
4. **方案评审**
   - 架构师终审：AI 方案必须**人工把关（Human Gate）**
**注意事项**

- 架构必须**可降级**：AI 挂了能切静态/兜底
- 接口统一规范：AI 生成代码必须遵守

## 五、项目初始化（Cursor + Claude）

**参与角色**：开发组长、全栈/前端/后端开发
**步骤与工具用法（Cursor 为主）**

1. **Git 初始化**
   - `git init` → `.gitignore`（Cursor 可生成）
2. **Cursor 项目规则**
   - 新建 `.cursor/rules`（前面已写）
   - 命令：`generate cursor rules`（AI 分析现有代码生成规则）
3. **项目骨架生成**
   - **Cursor Agent（Ctrl+I）**：

     ```
     用Vue3+TS+Vite创建项目骨架：
     - 目录：src/components, src/views, src/router, src/store, src/utils, src/api
     - 集成：ESLint, Prettier, Axios, Pinia
     - 基础布局、登录页框架、404页
     ```

   - Cursor 自动创建文件、写基础代码
4. **环境配置**
   - `.env.development` / `.env.production`（Cursor 生成）
5. **Claude 复核**
   - 把整个骨架发给 Claude：`检查结构、规范、依赖、安全风险`
**注意事项**

- 统一依赖版本、严格 Lint 规则
- 敏感配置（密钥）不进 Git

## 六、AI 辅助开发（核心阶段：Claude + Cursor 双剑合璧）

**参与角色**：前端、后端、AI 应用工程师

### 模式A：复杂模块 → Claude 生成 → Cursor 优化（推荐）

1. **Claude 生成完整模块**
   - Prompt（精准）：

     ```
     用TypeScript+Express实现【用户管理模块】：
     - 接口：注册/登录/退出/信息/改密/列表/分页/状态
     - JWT鉴权、密码加密、参数校验、错误处理
     - 遵循项目架构：controller/service/model/middleware
     - 代码带完整注释、单元测试框架
     输出完整文件：
     - user.controller.ts
     - user.service.ts
     - user.model.ts
     - auth.middleware.ts
     ```

   - Claude 一次性输出**全套可运行代码**
2. **Cursor 本地落地**
   - 复制到 Cursor → 按 Tab 补全、自动格式化
   - Ctrl+L 聊天：`优化命名、补类型、修复ESLint、加边界处理`
   - 内联修改（选中代码 → Ctrl+K → 指令）

### 模式B：快速迭代 → Cursor 写 → Claude 深度优化

1. **Cursor 快速写**
   - 单行/多行补全（Tab）
   - Ctrl+K：`实现XX函数，参数XX，返回XX`
   - Ctrl+L：`解释这段代码、找Bug、重构`
2. **Claude 深度优化**
   - 把文件发给 Claude：

     ```
     按项目规范优化代码：
     - 性能、可读性、异常处理
     - 提取复用、注释标准化
     - 安全：防注入、越权
     ```

### 模式C：AI 模块（RAG/Prompt/Agent）→ Claude 主导

1. **Prompt 工程**
   - Claude：`设计系统Prompt，满足：角色、约束、输出格式、幻觉过滤、步骤`
   - 多版本对比、测试准确率
2. **RAG 流程**
   - Claude：生成文档加载、分块、向量入库、检索、回答拼接全流程代码
3. **Cursor 调试**
   - 本地运行、打日志、测边界、调参

### 开发阶段标准流程（单功能）

1. 任务认领：从看板拿任务
2. **Prompt 设计**（人写，AI可优化）
3. **Claude 生成初版**（完整文件/函数）
4. **Cursor 本地调整**（补全、修复、格式化）
5. **单元测试**（Cursor 生成 → Ctrl+Shift+T）
6. **代码评审（人）**：必审，**AI代码不能直接合主干**
7. Git 提交：`feat: 用户登录模块（AI生成+人工优化）`
**注意事项**

- **人工必审**：安全/支付/权限核心代码严禁纯AI
- 统一AI产出规范：目录、命名、注释、错误码
- 每完成一小功能就提交Git，方便回退

## 七、测试（AI 生成用例 + 人工验证）

**参与角色**：测试工程师、开发、产品、AI 应用工程师

### 1. 单元/接口测试

- **Cursor**：选中函数 → `生成完整单元测试，覆盖所有分支、边界、异常`
- **Claude**：批量生成测试用例、测试数据、自动化脚本

### 2. AI 专项测试（必加）

- **Claude**：

  ```
  对以下AI功能做测试设计：
  - 幻觉测试：生成误导问题，检查是否胡编
  - 上下文测试：多轮对话一致性
  - 知识库准确率：检索精度、漏检/错检
  - 安全测试：Prompt注入、敏感信息泄露
  - 压力测试：并发、延迟、超时
  ```

- 人工执行+记录指标：**准确率、召回率、幻觉率、响应时间**

### 3. 集成 & 联调

- Cursor：运行、调试接口、日志分析
- Claude：分析报错、定位跨模块问题

### 4. UAT 用户验收

- 产品+业务：按PRD验收
- AI模块：**效果指标必须达标**
**注意事项**
- AI系统必须做**对抗性测试**（防注入、诱导）
- 建立测试集：标准答案库，每次迭代回归

**参与角色**：运维、研发、产品、运营、AI 应用工程师

## 十二、关键注意事项（AI + Claude + Cursor 专属）

1. **人在回路（Human-in-the-Loop）**
   - AI 是工具，**所有产出必须人工评审**：代码、架构、需求、测试
   - 核心逻辑/安全/支付/权限：**人写为主，AI辅助**
2. **Prompt 质量决定一切**
   - 清晰：语言、功能、输入输出、规范、边界、安全
   - 模板化：`任务 + 规则 + 上下文 + 输出格式 + 验收标准`
3. **Cursor Rules 是项目基石**
   - 必须写 `.cursor/rules`，团队统一，AI 才不乱写
4. **长上下文用好**
   - Claude/Claude 4：200k+ tokens，可一次性分析整个项目
5. **AI 债务管控**
   - 定期重构 AI 生成代码
   - 统一注释、规范、复用、测试覆盖率
6. **安全合规**
   - 数据脱敏、隐私、内容风控、审核机制
   - 防 Prompt 注入、越权、信息泄露
