本文档定义经济模型系统V2的**产品功能、交互逻辑、数据规则、权限、验收标准**，作为项目研发、测试、验收的唯一依据。

### 1.2 参考文档

- v1_v2_upgrade_requirements.md（升级需求）

## 2 产品概述

### 2.1 产品定位

企业级**经济模型在线协作测算平台**，解决v1计算不准、无协作、无合规、无后端的核心问题，实现财务公式精准计算、多人实时协作、内网本地化部署、全流程安全合规。

### 2.2 核心价值

- 公式零误差：对标Excel财务函数计算标准
- 协作无冲突：多人同步编辑不丢数、不冲突
- 数据安全：全操作审计、细粒度权限管控
- 兼容易用：1:1兼容v1 Excel模板，零学习成本

## 3 目标用户与使用场景

### 3.1 目标用户

| 用户角色 | 核心诉求 |
| ---- | ---- |
| 业务填报员 | 快速编辑单元格、导入Excel、查看计算结果 |
| 财务分析师 | 精准财务计算、公式编辑、版本管理 |
| 项目管理员 | 模型管理、版本锁定、权限分配、数据导出 |
| 集团管理员 | 系统权限管控、操作审计、数据安全管理 |

### 3.2 核心使用场景

1. 单人快速创建/编辑经济模型，自动计算财务指标
2. 多部门协同编辑同一模型，实时同步数据
3. 模型版本提交/锁定，防止误修改
4. Excel模板批量导入/导出，复用历史数据
5. 管理员管控操作权限，审计全流程操作

## 4 功能需求（按优先级）

### 4.1 P0 核心必选功能（第一阶段上线）

#### 4.1.1 模型管理

1. 模型列表：展示模型名称、创建人、创建时间、操作（编辑/删除/查看）
2. 模型创建：填写模型名称、类型、描述，创建空白模型
3. 模型编辑：修改模型基础信息，已关联版本的模型不可删除
4. 模型删除：仅无版本的空白模型可删除

#### 4.1.2 版本管理

1. 版本列表：按模型展示版本，标注状态（草稿/已提交/已锁定）
2. 版本创建：基于模型创建新版本，默认状态为**草稿**
3. 版本状态流转：草稿→已提交→已锁定，不可逆
4. 版本操作：草稿可编辑/保存/提交；已提交可查看/锁定；已锁定仅可查看
5. 版本删除：仅**草稿**状态可删除

#### 4.1.3 表格编辑

1. 树形表格：展示指标层级，支持展开/折叠
2. 单元格编辑：**双击**进入编辑模式，回车/失焦保存
3. 虚拟滚动：1000行数据流畅渲染，无卡顿
4. 数据格式化：自动展示千分位、百分比、绝对值、空值处理

#### 4.1.4 公式计算

1. 自动计算：编辑单元格后，自动触发公式重算
2. 支持函数：SUM/XIRR/XNPV/NPV/IRR等财务函数
3. 依赖检测：自动识别公式依赖，循环依赖给出提示
4. 计算结果：实时展示在对应单元格，精度保留4位小数

#### 4.1.5 Excel导入导出

1. 导入：兼容v1模板，一键导入数据、指标、公式
2. 导出：将模型数据、表格、计算结果导出为标准Excel
3. 导入校验：数据格式错误时，给出明确错误提示

### 4.2 P1 重要功能（第一阶段优化）

#### 4.2.1 权限控制

1. 权限矩阵：集团用户/锁定者/其他用户三级权限
2. 操作管控：查看/编辑/保存/提交/解锁权限隔离
3. 锁定版本：禁止任何编辑/修改操作

#### 4.2.2 数据展示优化

1. 单元格视觉状态：6种样式（加粗/斜体/标红/动画等）
2. 币种/单位适配：自动匹配币种、单位刻度

### 4.3 P2 扩展功能（第二阶段上线）

#### 4.3.1 多人实时协作

1. 多人同步编辑：多用户同时操作，数据实时同步
2. 光标同步：显示其他用户编辑位置
3. 操作冲突：自动合并，无数据丢失

#### 4.3.2 公式编辑器增强

1. 智能提示：输入`${`弹出指标选择框，支持模糊搜索
2. 语法高亮：区分指标/函数/常量
3. 公式版本回溯：查看历史公式，支持回滚

#### 4.3.3 系统保障

1. 错误定位：快速定位循环依赖、无效公式单元格
2. 自动备份：10分钟自动备份，支持一键恢复
3. 资源监控：监控公式复杂度、表格数据量

#### 4.3.4 AI智能助手

1. 自然语言查询：文字提问，自动生成数据结果
2. 模型解读：自动分析模型指标、计算结果

## 5 非功能需求

### 5.1 性能需求

1. 表格加载：≤2秒（1000行数据）
2. 公式计算：≤100毫秒（100个公式）
3. 页面响应：所有操作响应≤1秒

### 5.2 兼容需求

1. 浏览器：Chrome≥100、Edge≥100
2. 系统：Windows/macOS

### 5.3 安全需求

1. 敏感数据：全程脱敏存储
2. 操作审计：全流程操作日志留存
3. 数据隔离：基于用户角色做数据权限隔离

### 5.4 可用性需求

1. 新手引导：无引导即可完成基础操作
2. 错误提示：明确、可操作，无专业术语

## 6 数据需求

### 6.1 核心数据结构（复用v1）

1. 数据模型主表（datamodel）
2. 模型版本表（datamodelversion）
3. 指标定义表（modelmetric）
4. 单元格数据表（dataentry）
5. 公式定义表（modelformula）

### 6.2 数据规则

1. 版本状态：草稿/已提交/已锁定，不可逆
2. 公式格式：兼容`${metricCode-year}`格式
3. 数据格式化：千分位、百分比、绝对值自动处理

## 7 权限需求（直接复用v1）

| 操作 | 集团用户 | 锁定者 | 其他用户 | 已提交版本 |
| ---- | ---- | ---- | ---- | ---- |
| 查看 | ✅ | ✅ | ✅ | ✅ |
| 编辑 | ✅ | ✅（本人锁定） | ❌ | ❌ |
| 保存 | ✅ | ✅ | ❌ | ❌ |
| 提交 | ✅ | ✅ | ❌ | ❌ |
| 解锁 | ✅ | ❌ | ❌ | ✅（管理员） |

## 8 交互与视觉规范

### 8.1 交互规则

1. 单元格编辑：双击进入编辑，回车/失焦保存
2. 版本提交：二次确认，提交后不可编辑
3. 版本锁定：二次确认，锁定后仅管理员可解锁
4. 导入导出：进度条提示，完成后自动下载/提示成功

### 8.2 视觉风格

简约商务风，表格清晰、数据易读，操作按钮突出。

## 10 验收标准

### 10.1 功能验收

1. 模型/版本增删改查正常，状态流转正确
2. 单元格编辑、公式计算精准，对标Excel结果
3. Excel导入导出正常，兼容v1模板
4. 权限管控生效，锁定版本不可编辑

### 10.2 性能验收

1. 1000行表格加载≤2秒
2. 公式计算响应≤100毫秒
3. 虚拟滚动流畅无卡顿

## 11 附录

### 11.1 术语说明

- XIRR：不定期现金流内部收益率
- XNPV：不定期现金流净现值
- CRDT：无冲突复制数据类型（多人协作核心）
- RAG：检索增强生成（AI助手核心）

### 11.2 异常问题处理

1. 公式循环依赖：提示「存在循环依赖，请检查公式」
2. 导入格式错误：提示「第X行X列数据格式错误」
3. 无权限操作：提示「您无此操作权限」
