# Cursor + Claude Code 组合使用 完整复盘版（咱们之前约定的全套工作流）

## 一、核心定位（先定角色，不越位）

### 1. Cursor

**定位：本地IDE贴身编码助手**

- 嵌入代码编辑器，**实时写代码、补全、单文件逻辑、局部调试**
- 适合：写业务组件、接口封装、页面逻辑、Vue3/Nuxt3/小程序单页开发、小bug修复
- 优势：懂当前文件上下文、光标所在位置，随手改、随手补，开发不切窗口

### 2. Claude Code（终端版）

**定位：项目级全局架构助手**

- 终端运行，**跨多文件全局理解、架构设计、批量重构、工程化部署、复杂排障**
- 适合：项目初始化、目录规范、全项目批量改语法、Docker配置、MySQL/Redis排障、RAG项目整体逻辑、毕业设计项目架构梳理
- 优势：能读懂整个项目结构、依赖关系，做宏观设计和批量改动

## 二、固定分工原则（咱们定好的边界）

1. **写单页/单组件/单个函数 → 只用 Cursor**
2. **搭架构/建项目目录/跨多文件改代码 → 交给 Claude Code**
3. **代码语法小错、格式优化、变量命名 → Cursor**
4. **报错日志分析、容器启动失败、环境配置、线上部署排障 → Claude Code**
5. **写接口文档、项目说明、毕设论文技术描述 → 两者配合**
   - Cursor：生成代码片段示例
   - Claude Code：整合成规范文档/论文章节

## 三、标准开发全流程（可直接套用）

### 步骤1：需求拆解 & 架构规划

用 **Claude Code**

- 输入项目需求（如Nuxt3个人博客、小程序后台、RAG私有化平台）
- 让它输出：目录结构、技术栈选型、模块拆分、接口设计

### 步骤2：项目初始化 & 骨架搭建

用 **Claude Code**

- 生成初始化命令、依赖安装、配置文件（nuxt.config、docker-compose、eslint 等）
- 一次性生成基础骨架代码

### 步骤3：业务页面/组件开发

切 **Cursor**

- 按架构逐个写页面、组件、API 请求
- 实时补全、模板生成、样式适配、逻辑调试

### 步骤4：跨文件统一重构/规范统一

切 **Claude Code**

- 全局统一接口返回格式、全局错误处理、统一命名规范
- 批量修改多个文件的重复逻辑

### 步骤5：Bug 调试 & 日志排障

1. 小范围逻辑bug → Cursor 直接断点+分析修改
2. 环境/容器/数据库/依赖报错 → 把完整日志丢给 **Claude Code** 直接给修复命令和改代码

### 步骤6：部署 & 工程化

**Claude Code 全包**
Docker 打包、镜像构建、容器启停、Nginx配置、服务器环境排查

## 四、适配你技术栈的专属用法

1. **Nuxt3 / Vue3 / 小程序**

- Cursor：写页面、组件、生命周期、ECharts 封装、登录鉴权逻辑
- Claude Code：全局路由封装、状态管理规范、项目配置、批量兼容调整

1. **Docker / MySQL / Redis 运维**

- 全部用 Claude Code：写docker-compose、排障启动失败、数据库脚本、索引优化

1. **RAG / 向量库 / AI 应用**

- Claude Code：整体架构、知识库拆分、检索逻辑、私有化部署方案
- Cursor：写单个调用函数、接口封装、前端展示页面

1. **本科毕设（全栈博客系统）**

- Claude Code：项目整体架构、技术原理描述、论文技术章节初稿
- Cursor：生成关键代码片段、完善功能实现代码

## 五、高阶联动技巧

1. 先让 **Claude Code 输出项目规范和目录**，再到 Cursor 里逐文件开发，完全对齐规范
2. 复杂需求先用 Claude Code 拆解成小任务，再丢给 Cursor 逐个实现
3. 遇到大段烂代码：Claude Code 全局重构，Cursor 做细节微调
4. 不用来回复制代码：Claude Code 可直接读取项目文件，全局理解上下文

## 六、避坑规则

- 不要用 Cursor 做跨几十文件的大重构，容易逻辑割裂
- 不要用 Claude Code 写细小UI组件、页面细节，效率低
- 固定搭配：**宏观架构/工程化→Claude Code，微观编码/页面开发→Cursor**

Cursor + Claude Code 专属Prompt模板

## 一、 Cursor 专用 Prompt

### 模板1：通用编码规范（固定人设）

你现在是资深前端全栈工程师，严格遵循：代码简洁、低冗余、注释精简、TS类型完整、符合工程规范。只专注当前文件上下文，只做局部编码、组件编写、逻辑补全、小bug修复，不做跨文件全局架构设计。

### 模板2：Vue3 / 小程序 组件生成

帮我写一个Vue3组合式API/微信小程序原生组件，包含：props类型定义、核心业务逻辑、样式适配、基础事件封装，代码结构清晰，加必要注释，不要冗余代码。

### 模板3：代码优化&重构

帮我优化当前这段代码：精简逻辑、提取公共方法、规范变量命名、完善类型校验、消除冗余判断，保留原有业务逻辑不变。

### 模板4：局部Bug调试

帮我分析这段代码报错原因，逐行定位问题，给出最小改动修复方案，顺带优化潜在隐患，不用重构整体结构。

## 二、 Claude Code 终端专用 Prompt（终端直接输入）

### 模板1：项目架构拆解

帮我对当前项目做整体架构设计：梳理目录结构、拆分模块、定义技术栈规范、划分接口层级、给出开发先后顺序，输出可直接落地的项目目录和规范文档。

### 模板2：新项目一键初始化

帮我在当前目录初始化项目，完成：依赖安装、配置文件生成、目录分层、基础工具封装、ESLint/环境变量配置，给出所有执行命令和配置代码。

### 模板3：跨文件批量全局重构

帮我全局遍历项目所有文件，统一规范：接口返回格式、请求封装、错误处理、命名风格、导入路径，批量修改并给出改动说明，保证业务逻辑不变。

### 模板4：Docker / MySQL / 日志排障

帮我分析以下报错日志，定位根因，给出可直接复制的修复命令、配置修改方案、容器/数据库启停排查步骤，一步步带我解决问题。

### 模板5：RAG / AI 应用架构设计

帮我设计私有化RAG系统整体架构：知识库分层、向量库选型、检索逻辑、召回策略、前后端交互流程、部署方案，输出完整架构思路和模块拆分。

### 模板6：毕设/技术文档撰写

基于当前项目代码，帮我撰写毕业设计技术章节：技术选型原理、系统架构说明、核心模块流程、关键代码解析，语言学术规范，贴合本科毕设写作风格。

`Claude Code先帮我拆需求+搭目录架构，我再用Cursor逐文件开发`
2. 先重构后微调：
`Claude Code全局批量重构，之后我用Cursor做细节UI和逻辑微调`
3. 报错分工：
`环境/日志问题交给Claude Code，页面逻辑小bug用Cursor快速修复`
