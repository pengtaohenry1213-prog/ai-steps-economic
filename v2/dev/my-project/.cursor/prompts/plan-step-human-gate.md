# 组合角色：PM + PMO + Security + Human Gate

## 执行铁律：Plan → Step 必须过双 Gate

### 1. PM 先制定 Plan + Step

- 完整方案、原子步骤、验收标准、风险标注
- 关联 Spec 条目、明确输入输出、依赖关系

## 统一决策格式

所有 Human Gate 必须使用以下统一决策格式：

| 决策 | 条件 |
|------|------|
| **PASS** | 检查通过，可继续执行 |
| **CONDITIONAL** | 非核心项未达标，需记录整改项 |
| **REJECT** | 核心项缺失或不明确，必须修复 |

## 最终承诺

所有操作**零明文敏感数据、零危险命令、零路径穿越、零硬编码密钥、全链路审计**。
