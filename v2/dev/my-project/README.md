# my-project

## 项目介绍

基于 Vue3, TypeScript, Vite, vxe-table, HyperFormula, Supabase, Yjs 构建的现代化应用。

## 技术栈

- Vue3
- TypeScript
- Vite
- vxe-table
- HyperFormula
- Supabase
- Yjs

## 快速开始

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 运行测试
pnpm test

# 构建生产版本
pnpm build
```

## 项目结构

```
src/
├── components/   # 组件
│   ├── views/        # 页面
│   ├── stores/       # 状态管理
│   ├── api/          # API 层
│   ├── types/        # 类型定义
│   └── utils/        # 工具函数
├── packages/         # 共享包
└── ...
```
