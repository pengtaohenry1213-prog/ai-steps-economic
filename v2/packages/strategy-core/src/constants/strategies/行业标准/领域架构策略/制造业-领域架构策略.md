## 二、技术选型要点

### 2.1 工业协议

| 协议 | 类型 | 适用场景 |
|-----|------|---------|
| **OPC-UA** | 信息模型 | 跨厂商设备通信 |
| **MQTT** | 消息传输 | IoT 设备低带宽 |
| **Modbus** | 串行通信 | 传统设备 |
| **Profinet** | 实时以太网 | 西门子设备 |
| **EtherCAT** | 高速运动控制 | 运动控制 |

### 2.2 数据处理架构

| 层级 | 技术 | 说明 |
|-----|------|------|
| **实时处理** | Apache Flink / Spark Streaming | 毫秒级处理 |
| **批量处理** | Apache Spark | 大数据处理 |
| **时序存储** | TimescaleDB / InfluxDB | 设备数据 |
| **消息队列** | Apache Kafka | 高吞吐 |

## 三、集成模式

### 3.1 ERP/MES集成

| 方向 | 内容 | 方式 |
|-----|------|------|
| **ERP → MES** | 工单、物料、BOM | API / 中间件 |
| **MES → ERP** | 报工、产量、质检 | API / 中间件 |
| **实时同步** | 库存、工单状态 | 消息队列 |

### 3.2 设备集成

| 集成方式 | 说明 |
|---------|------|
| **OPC-UA** | 现代设备，支持信息模型 |
| **PLC直接采集** | 旧设备，Modbus协议 |
| **边缘网关** | 协议转换 + 边缘计算 |
| **SCADA对接** | 已有的SCADA系统 |

### 3.3 质量追溯集成

```
原材料入库 → 生产工单 → 工序报工 → 质量检验 → 成品入库 → 发货
    │           │           │           │           │          │
    ▼           ▼           ▼           ▼           ▼          ▼
  批次号     工单号      工序记录     质检数据    批次号    追溯码
```

## 四、安全架构

### 4.1 IT/OT安全隔离

```
┌─────────────────┐         ┌─────────────────┐         ┌─────────────────┐
│    企业网络     │         │   DMZ 区域      │         │   生产网络       │
│    (IT)        │         │ (防火墙+审计)    │         │    (OT)         │
│                 │         │                 │         │                 │
│  ┌───────────┐  │         │ ┌───────────┐   │         │  ┌───────────┐  │
│  │   ERP     │◀┼─────────┼▶│安全网关   │◀┼─────────┼─▶│   MES     │  │
│  └───────────┘  │         │ └───────────┘   │         │  └─────┬─────┘  │
│                 │         │                 │         │        │        │
│  ┌───────────┐  │         │ ┌───────────┐   │         │  ┌─────▼─────┐  │
│  │   OA     │◀┼─────────┼▶│日志审计   │◀┼─────────┼─▶│   SCADA   │  │

```

### 4.2 工控安全要求

| 要求 | 说明 |
|-----|------|
| **网络分段** | IT/OT 网络物理隔离 |
| **边界防护** | 工业防火墙 |
| **设备认证** | PLC、设备的接入认证 |
| **操作审计** | 操作日志完整记录 |
| **补丁管理** | 工控设备补丁需测试 |

## 五、高可用架构

### 5.1 冗余设计

| 类型 | 方案 | 说明 |
|-----|------|------|
| **设备冗余** | 双网口、双PLC | 硬件冗余 |
| **网络冗余** | 双网络、双路由 | 网络冗余 |
| **服务冗余** | 双机热备 | 软件高可用 |

### 5.2 实时性保障

| 要求 | 方案 |
|-----|------|
| **毫秒级响应** | 边缘计算，本地处理 |
| **秒级响应** | 异步 + 批量处理 |
| **分钟级响应** | 云端服务处理 |

## 六、监控体系
