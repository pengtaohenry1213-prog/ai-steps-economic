## 二、技术选型要点

### 2.1 前端技术栈

| 层级 | 技术 | 说明 |
|-----|------|------|
| **小程序** | 原生/uni-app | 多端小程序 |
| **Web** | Vue3 / React | 电商网站 |
| **门店端** | Electron / Flutter | 桌面/移动 |
| **组件库** | Vant / Element Plus | 移动/PC |

### 2.2 后端技术栈

| 层级 | 技术 | 说明 |
|-----|------|------|
| **语言** | Java / Go / Python | 按场景选择 |
| **微服务** | Spring Cloud / Dubbo | 大型平台 |
| **消息队列** | RocketMQ / Kafka | 异步解耦 |
| **缓存** | Redis Cluster | 高并发 |

### 2.3 数据库选型

| 类型 | 技术 | 适用场景 |
|-----|------|---------|
| **关系型** | MySQL / PostgreSQL | 订单、库存 |
| **文档型** | MongoDB | 商品详情、促销 |
| **缓存** | Redis | 会话、热点数据 |
| **搜索** | Elasticsearch | 商品搜索 |

## 六、高可用架构

### 6.1 促销高峰应对

| 场景 | 方案 |
|-----|------|
| **秒杀** | 令牌桶 + 限流 |
| **抢购** | 库存预占 + 消息队列 |
| **促销** | CDN + 就近接入 |

### 6.2 门店离线方案

| 方案 | 说明 |
|-----|------|
| **本地缓存** | 门店POS本地缓存商品、促销 |
| **离线收银** | 网络断开可继续收银 |
| **网络恢复** | 自动同步离线数据 |
