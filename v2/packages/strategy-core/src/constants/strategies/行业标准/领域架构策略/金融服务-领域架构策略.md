## 二、技术选型要点

### 2.1 核心系统技术选型

| 层级 | 技术 | 说明 |
|-----|------|------|
| **数据库** | Oracle / DB2 / PostgreSQL | 银行核心主流 |
| **中间件** | IBM MQ / TIBCO | 交易消息 |
| **批处理** | COBOL / Hadoop | 日终批处理 |
| **分布式** | Spring Cloud / Dubbo | 微服务化 |

### 2.2 分布式事务方案

| 方案 | 适用场景 | 说明 |
|-----|---------|------|
| **两阶段提交（2PC）** | 强一致性 | 锁定资源，性能差 |
| **TCC** | 最终一致 | 业务编排 |
| **Saga** | 长事务 | 补偿模式 |
| **本地消息表** | 异步最终一致 | 可靠消息 |

### 2.3 账务设计原则

```
┌─────────────────────────────────────────────────────────────┐
│                      账务设计原则                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 双记账：每笔交易同时记借方和贷方，账务必平衡              │
│                                                             │
│  2. 幂等性：同一笔交易多次执行结果一致                       │
│                                                             │
│  3. 日终平衡：日终试算平衡，有借必有贷，借贷必相等           │
│                                                             │
│  4. 事务原子性：账户金额变更原子完成                         │
│                                                             │
│  5. 实时监控：异常余额实时告警                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 四、安全架构

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│    互联网区域   │     │    DMZ 区域     │     │   核心区域      │
│                 │     │                 │     │                 │
│  ┌───────────┐  │     │ ┌───────────┐   │     │ ┌───────────┐  │
│  │  网银前置  │◀─┼─────┼▶│  防火墙    │◀──┼─────┼─▶│  核心系统  │  │
│  └───────────┘  │     │ └───────────┘   │     │  └───────────┘  │
│                 │     │                 │     │                 │
│  ┌───────────┐  │     │ ┌───────────┐   │     │ ┌───────────┐  │
│  │  手机银行  │◀─┼─────┼▶│  IDS/IPS   │◀──┼─────┼─▶│   数据库   │  │
│  └───────────┘  │     │ └───────────┘   │     │  └───────────┘  │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

### 4.2 数据安全

| 措施 | 说明 |
|-----|------|
| **敏感加密** | 账户、密码、密钥加密存储 |
| **传输加密** | TLS/SSL |
| **数据脱敏** | 日志、测试环境脱敏 |
| **密钥管理** | HSM 硬件加密机 |

### 4.3 身份认证

| 级别 | 方式 |
|-----|------|
| **基础** | 用户名 + 密码 |
| **增强** | + 短信验证码 |
| **高级** | + 动态令牌/USB Key |
| **交易级** | 交易密码 + 动态令牌 |

## 五、高可用架构

### 5.1 银行核心高可用

| 方案 | 说明 |
|-----|------|
| **两地三中心** | 同城容灾 + 异地灾备 |
| **双活** | 主备切换，RTO < 5分钟 |
| **数据同步** | 实时同步，RPO = 0 |

### 5.2 性能要求

| 指标 | 要求 |
|-----|------|
| **核心交易** | < 500ms |
| **日终批处理** | 天亮前完成 |
| **并发能力** | 万级并发 |
