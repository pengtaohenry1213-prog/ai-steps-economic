。apps/web 是一个AI 驱动的项目文档生成器，工作流程如下：

  用户输入（自然语言需求）
         ↓
  ┌─────────────────────────────────────────────────────────┐
  │ 1. 策略匹配 (matchStrategyWithAIService)               │
  │    用户需求 → 匹配预定义策略（T1-T14）                   │
  └─────────────────────────────────────────────────────────┘
         ↓
  ┌─────────────────────────────────────────────────────────┐
  │ 2. 策略增强 (enhanceStrategyWithAIService)              │
  │    策略 + 用户需求 → 增强后的详细策略定义                 │
  └─────────────────────────────────────────────────────────┘
         ↓
  ┌─────────────────────────────────────────────────────────┐
  │ 3. 交付物生成 (generateAllDeliverablesWithAIService)   │
  │    ├─ 立项书 (proposal)                                 │
  │    ├─ 需求文档 (requirements/prd)                       │
  │    └─ 架构设计 (architecture)                          │
  └─────────────────────────────────────────────────────────┘
         ↓
  ┌─────────────────────────────────────────────────────────┐
  │ 4. Step 生成 (generateStepDocumentsFromArchitecture)    │
  │    架构 → 多个 Step 文件（step1, step2, ...）            │
  └─────────────────────────────────────────────────────────┘
         ↓
  ┌─────────────────────────────────────────────────────────┐
  │ 5. 开发路线 (generateStepsDevDocument)                 │
  │    Steps → steps-dev 开发执行路线                       │
  └─────────────────────────────────────────────────────────┘
         ↓
  📦 ZIP 一键导出（含文档 + Cursor 规则）

  核心特性：
  - 支持上传 .md 文件自动提取关键段落（项目愿景/升级目标/技术栈/复用资产）
  - localStorage 缓存各阶段文档（刷新不丢失）
  - 已生成文档自动跳过，支持单独重新生成
  - 内置 AI JSON 解析重试机制

  输出文档：
  | 文档                        | 说明         |
  |---------------------------|------------|
  | strategy.md               | 匹配的策略及增强内容 |
  | proposal.md               | 立项书        |
  | requirements.md           | 需求文档（PRD）  |
  | architecture.md           | 架构设计       |
  | steps.md / doc/steps/*.md | Step 任务列表  |
  | steps-dev.md              | 开发执行路线     |
