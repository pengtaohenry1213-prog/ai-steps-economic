> **文档版本**: v1.0.0

## 一、项目愿景

构建新一代经济模型在线协作平台，实现：

| 目标 | 说明 |
|------|------|
| **公式零误差** | 财务公式计算 100% 准确，支持 XIRR/XNPV/NPV/IRR 等专业财务函数 |
| **多人实时协作** | 支持团队成员同时编辑同一模型，实时同步无冲突 |
| **内网可部署** | 支持本地化部署，数据不出企业 |
| **安全合规** | 完整操作审计，满足等保要求 |

**相比 v1 的核心升级**：从单人离线编辑 → 多人在线协作，从自研公式引擎 → 专业 HyperFormula 引擎

## 二、功能规划

### 2.1 功能优先级矩阵

| 优先级 | 功能模块 | 功能点 | 业务价值 |
|--------|----------|--------|----------|
| **P0** | 表格编辑 | 双击单元格编辑、虚拟滚动（1000+行流畅） | 核心使用场景 |
| **P0** | 公式引擎 | SUM/XIRR/XNPV/NPV/IRR 计算 | 财务计算必需 |
| **P0** | 版本管理 | 创建/编辑/提交/锁定模型版本 | 版本控制与合规 |
| **P0** | 数据导入导出 | Excel 模板导入/导出 | 与现有流程兼容 |
| **P1** | 树形表格 | 指标层级展示与折叠 | 提升可读性 |
| **P1** | 数据格式化 | 千分位/百分比/绝对值显示 | 数据可读性 |
| **P1** | 权限控制（RBAC）| 集团用户/锁定者/其他用户权限矩阵 | 安全保障 |
| **P2** | 多人协作 | 实时编辑、光标同步、冲突解决 | 团队协作（第二阶段） |
| **P2** | AI 智能助手 | 自然语言查询、数据解读 | 提升效率（第三阶段） |

## 三、里程碑计划

| 阶段 | 工期 | 主要交付物 |

## 六、技术架构（概要）

```
┌─────────────────────────────────────────────────────┐
│                    前端 (Vue 3)                     │
├─────────────────────────────────────────────────────┤
│  表格组件 (vxe-table)  │  状态管理 (Zustand)        │
│  公式引擎 (HyperFormula + v1 财务函数)             │
│  协作层 (Yjs - 第二阶段)  │  Mock Service          │
└─────────────────────────────────────────────────────┘
                          │
              ┌──────────┴──────────┐
              │   localStorage      │  ← 第一阶段存储
              │   (或 Supabase)     │  ← 第二阶段存储
              └─────────────────────┘
```

**技术栈**：
- 前端：Vue 3 + TypeScript + Vite + Tailwind CSS
- 表格：vxe-table（虚拟滚动、双击编辑）
- 公式：HyperFormula + v1 财务函数（XIRR/XNPV/NPV/IRR）
- 状态：Zustand（轻量、Yjs 友好）
- 存储：localStorage（第一阶段）→ Supabase（第二阶段）
- 协作：Yjs CRDT（第二阶段）
- AI：RAG + LLM（第三阶段）

## 七、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| Excel 导入解析异常 | 功能不稳定 | 使用稳定版 exceljs，编写详细测试 |
| 公式计算结果差异 | 数据不准确 | 全面回归测试，特别是财务函数 |
| v1 → v2 数据迁移 | 历史数据丢失 | 充分验证数据兼容性 |
| localStorage 容量 | 大数据量存储失败 | 考虑 IndexedDB 备选方案 |
