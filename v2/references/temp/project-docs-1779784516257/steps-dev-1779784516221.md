# 开发路线

此文档是产品实现步骤与 Agent 执行指南，由 **TechLead** 负责维护。

## Agent 执行方案（Plan 中间层）

> 每次执行 step 前，先用 Plan 模式生成 `.cursor/plans/stepN-plan.md`，再由 Agent 执行。
> 详见 [.cursor/plans/README.md](./.cursor/plans/README.md)

### 工作流约定

| 顺序 | 步骤 | 说明 |
| ---- | ------------- | -------------------------------------------------------------------------- |
| 1 | **读取规格** | 读取 `doc/steps/stepN.md` 了解任务目标、要求、强约束 |
| 2 | **生成 Plan** | Plan 模式生成 `.cursor/plans/stepN-plan.md`（todos + 文件清单 + 验收标准） |
| 3 | **执行 Plan** | Agent 模式按 todos 顺序执行代码 |
| 4 | **验收闭环** | 对照 Plan 里的验收标准逐项确认 |

### 为什么用 Plan 作为中间层

- **规格与执行解耦**：`stepN.md` 是「做什么」，`stepN-plan.md` 是「怎么做、做成什么样」
- **减少执行跑偏**：todos 相当于执行路线图，AI 不会漏掉步骤或误解需求
- **可追溯**：每次执行都有 Plan 记录存档，回溯「当时为什么这么实现」比翻对话记录清晰

## 正确的开发顺序

### 阶段划分与依赖逻辑

| 阶段 | 包含步骤 | 核心依赖逻辑 |
| ------ | -------- | ------------------------------------------------ |
| 第零阶段：项目初始化 | step0 | 所有开发的前置，搭建 monorepo 结构，是项目基础设施的根本 |
| 第一阶段：基础搭建 | step1、step6 | step1（后端基础设施）和 step6（AI能力服务）可以并行开发，形成前后端基础项目结构 |
| 第二阶段：核心功能链路 | step2、step3、step4、step5、step7、step8、step9 | 后端 API 优先，step1 完成后再开发 step2 前端认证，避免 Mock；后续步骤顺序依赖，前端界面与后端服务交替推进 |
| 第三阶段：集成与部署 | step10 | 所有功能模块就绪后，进行集成测试与部署验证，完成完整流程闭环 |

### 为什么这样排序

- **第零阶段：项目初始化**：所有开发的前置，搭建 monorepo 结构，是项目基础设施的根本
- **第一阶段：基础搭建**：step1（后端基础设施）和 step6（AI能力服务）可以并行开发，形成前后端基础项目结构

### 各阶段详细步骤

#### 第零阶段：项目初始化

| step | 任务目标 | 说明 |
| ----- | ---------------------- | ----------------------------------------- |
| step0 | 搭建 monorepo 结构与基础配置 | 建立项目根目录结构，配置 pnpm workspaces，搭建前后端基础目录，规划统一规范 |

#### 第一阶段：基础搭建

| step | 任务目标 | 说明 |
| ----- | ---------------------- | ----------------------------------------- |
| step1 | 后端基础设施与认证模块 | 数据库连接配置，JWT 认证模块，密码加密，用户注册登录 API |
| step6 | AI 能力服务 | MiniMax API 集成，智能公式建议，数据分析等 AI 功能接入 |

#### 第二阶段：核心功能链路

| step | 任务目标 | 说明 |
| ----- | ---------------------- | ----------------------------------------- |
| step2 | 前端认证界面 | 登录注册页面开发，Token 管理，JWT 解析，持久化登录状态 |
| step3 | 数据模型管理 | 模型 CRUD 操作，指标定义，字段配置，数据结构设计 |
| step4 | 版本控制 | 版本历史记录，版本对比，版本回滚机制，变更追踪 |
| step5 | 公式计算引擎 | HyperFormula 集成，财务函数实现，公式解析与计算 |
| step7 | 导入导出功能 | Excel 解析，文件上传下载，批量数据处理 |
| step8 | 实时协作 | WebSocket 集成，实时数据同步，冲突检测与处理 |
| step9 | CI/CD 基础配置 | GitHub Actions 配置，自动化测试，自动化部署流水线 |

#### 第三阶段：集成与部署

| step | 任务目标 | 说明 |
| ----- | ---------------------- | ----------------------------------------- |
| step10 | 集成测试与部署 | 端到端测试，性能测试，生产环境部署，监控告警 |
